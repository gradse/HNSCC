# Results

- `figures/` contains the plots and tables used to assemble the poster.
- `figures/Kaplan_Meier_Survival_Curve_Corrected.png` uses death time for
  deceased patients and last follow-up time for living patients.
- `tables/` contains gene-level statistical summaries and the 93-gene table.
- `report/` contains the rendered R Markdown analysis.

Patient-level data files are not included.
